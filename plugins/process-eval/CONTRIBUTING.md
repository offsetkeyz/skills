# Contributing to process-eval

## Rules

- **One framework per PR.** Each PR adds one framework file, one eval case, and one routing row in `SKILL.md`.
- **Primary source required.** Cite the primary source with a URL (publisher, DOI, or standards-body page) that confirms author, title and year. Label every citation with its evidence type: `[book]`, `[peer-reviewed]`, `[standards body]` or `[practitioner]`.
- **Paraphrase only.** No quotes of 15 or more words.
- **Roles, not names.** Examples use roles and generic organizations ("office manager", "a 6-person accounting firm"), never real people or companies.
- **Tests pass.** `pytest plugins/process-eval/tests` must pass before review.
